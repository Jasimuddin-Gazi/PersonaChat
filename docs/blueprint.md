# **App Name**: PersonaChat

## Core Features:

- AI Persona Creation: Create and customize AI personas with specific roles (e.g., 'Business Mentor', 'Anime Friend'). The LLM is a tool for creating varied personas.
- Persona List: Display a list of created AI personas for the user to interact with.
- Chat Interface: Implement a simple chat interface for interacting with selected AI personas.

## Style Guidelines:

- Primary color: Neutral grays for a clean, modern look.
- Secondary color: Soft blues to convey trust and reliability.
- Accent: Teal (#008080) to highlight key interactive elements.
- Clean and intuitive chat interface layout.
- Use simple, recognizable icons for common actions (send, delete, etc.).
- Subtle transitions and animations for a smooth user experience.
